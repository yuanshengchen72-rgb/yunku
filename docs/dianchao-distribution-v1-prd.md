# 电潮分销 V1 产品需求文档

状态：需求已对齐，待技术方案确认  
整理日期：2026-08-28

## 1. 产品目标

在 1688 服务市场上架一个可实际使用的买家铺货工具。1688 用户订购后，从“使用服务”进入内嵌网页，将 1688 一件代发商品批量发布到其绑定的一个或多个微信小店。

V1 的首要目标是形成真实、完整且便于审核演示的最小铺货闭环，不建设商品云库、订单系统或复杂运营能力。

## 2. 已确认的产品原则

- 应用名称：电潮分销。
- 形态：1688 服务市场内嵌的 PC 网页应用。
- 身份来源：完全使用 1688 账号及订购/授权状态，不提供手机号、密码或短信登录。
- 下游渠道：V1 只支持微信小店。
- 微信小店接入：客户填写每个店铺自己的自研 `AppID + AppSecret`。
- 多店铺：一个 1688 账号可绑定多个微信小店。
- 批量铺货：每批最多 20 个 1688 商品，可同时选择多个微信小店。
- 套餐：首版免费上架，应用内不做支付、套餐和续费。
- 部署：正式服务部署在聚石塔；已选择原生 SAE 部署。

## 3. 用户与数据边界

### 3.1 用户身份

客户从 1688 服务市场订购后点击“使用服务”。系统根据 1688 授权信息识别账号，并校验订购资格。

### 3.2 租户隔离

每个 1688 账号只能访问自己的：

- 微信小店绑定信息；
- 商品导入数据；
- 铺货任务及结果；
- 操作记录。

所有业务查询都必须包含租户条件，禁止仅凭店铺 ID、商品 ID 或任务 ID 查询跨租户数据。

### 3.3 微信凭证

- 每个微信小店独立保存 `AppID` 和 `AppSecret`。
- `AppSecret` 只提交到后端，不在前端保存或回显。
- 数据库中加密存储 `AppSecret`。
- 日志中屏蔽密钥及完整 `access_token`。
- 每个店铺独立缓存和刷新 `access_token`。
- 解绑店铺时删除凭证、令牌和相关缓存。
- 聚石塔应用的固定出口 IP 需要加入每个微信小店的自研 IP 白名单。

## 4. V1 页面范围

### 4.1 链接铺货

1. 用户粘贴 1688 商品链接，每行一条，单批最多 20 条。
2. 系统解析链接或商品 ID，并批量读取商品资料。
3. 页面展示待铺货商品列表及无法导入的错误项。
4. 用户可对商品进行最小编辑。
5. 用户选择一个或多个已绑定微信小店。
6. 系统创建后台异步铺货任务。
7. 页面跳转或引导用户前往铺货记录查看结果。

### 4.2 货源搜索

- 输入关键词搜索 1688 商品。
- 展示主图、标题、价格和供应商等基础信息。
- 支持勾选最多 20 个商品进入批量铺货。
- 只做基础分页，不做高级筛选。
- 若当前解决方案没有对应接口权限，应显示真实的权限提示，不使用模拟商品冒充接口数据。

### 4.3 货源推荐

- 展示 1688 接口返回的默认推荐商品。
- 支持勾选最多 20 个商品进入批量铺货。
- 不做个性化推荐、排行榜或复杂标签体系。

### 4.4 微信小店管理

- 添加、编辑、验证和解绑多个微信小店。
- 保存店铺名称或用户备注，便于选择。
- 显示正常、凭证失效、IP 白名单异常等状态。
- 验证绑定时由后端获取微信 `access_token`，不得由浏览器直接请求微信接口。

### 4.5 铺货记录

每个“商品 × 店铺”生成独立子任务。记录至少包含：

- 1688 商品信息；
- 目标微信小店；
- 创建时间；
- 当前状态；
- 微信商品 ID（成功时）；
- 失败原因；
- 重试入口。

一个商品或店铺失败不得中断同批其他任务。

### 4.6 使用说明

- 如何取得微信小店自研 AppID/AppSecret；
- 如何配置聚石塔固定出口 IP 白名单；
- 如何批量铺货；
- 如何查看微信审核结果；
- 常见错误和处理方法；
- 客服联系方式。

## 5. 商品转换与编辑

### 5.1 默认复制字段

- 商品标题；
- 主图；
- 详情图/详情内容中可合法使用的部分；
- SKU 规格；
- SKU 价格；
- SKU 当前库存快照。

### 5.2 可编辑字段

- 商品标题；
- 微信小店类目；
- 售价；
- 库存；
- 删除不需要的主图。

### 5.3 批量售价规则

支持：

`微信售价 = 1688 原价 × 倍数 + 固定金额`

V1 不做复杂价格模板、分店铺价格模板或自动调价。

### 5.4 类目处理

- 根据 1688 类目自动推荐微信小店类目。
- 发布前由用户人工确认或修改。
- 优先支持普通商品类目。
- 对需要品牌授权、行业资质或额外字段的类目，提示用户补充材料；暂未实现时应明确提示不支持。

### 5.5 库存处理

- 使用导入时读取到的 1688 SKU 库存作为首次发布库存。
- 用户可在发布前修改。
- V1 不做 1688 库存自动同步。
- 页面明确提示库存是导入快照，发布后不会自动更新。

## 6. 发布及状态

提交铺货后，系统直接创建微信小店商品并提交平台审核，不额外保存为“电潮分销草稿”。

状态至少包括：

- 待处理；
- 处理中；
- 提交成功；
- 微信审核中；
- 已上架；
- 审核失败；
- 发布失败。

用户通过“刷新状态”主动查询微信最新状态。V1 暂不接入实时消息推送。

## 7. 明确不在 V1 范围

- 自有商品云库/PIM；
- UnoPim 集成；
- 订单、物流、售后和采购回流；
- 1688 商品价格及库存自动同步；
- 多下游渠道；
- 图片裁剪、AI 改图和详情装修；
- 复杂 SKU 编辑；
- 高级搜索、榜单及个性化推荐；
- 独立登录系统；
- 应用内付费及套餐管理；
- 实时消息推送；
- 手机端专项适配。

## 8. 部署现状与目标架构

### 8.1 已完成

- 已取得 1688 软件开发商资质。
- 已创建并订购服务商版解决方案的 1688 应用。
- 已登录与企业主体匹配的聚石塔账号。
- 已创建聚石塔电商云应用 `dianchao-distribution`。
- 部署类型已选原生 SAE。
- 已创建 `test` 测试环境，地域为 `cn-zhangjiakou`。
- 已开通 SAE 服务及服务关联角色。

### 8.2 目标架构

```text
1688 服务市场/内嵌容器
          │
          ▼
聚石塔 SAE：电潮分销 Web/API
    ├── 1688 OAuth 与商品接口
    ├── 微信小店连接器
    ├── 批量铺货任务
    └── 租户及凭证管理
          │
          ├── RDS MySQL（业务数据）
          ├── 缓存/任务组件（按实现需要）
          ├── 手动创建的负载均衡（入站）
          └── NAT 网关 + 固定 EIP（出站）
                         │
                         └── 1688 API / 微信小店 API
```

正式环境需要另行创建，不复用测试环境。SAE、VPC、负载均衡、NAT、EIP 和数据库必须选择兼容地域并按聚石塔要求关联。

## 9. 安全与合规要求

- 1688 和微信接口都由后端调用。
- AppSecret、Token、数据库密码不得进入前端包、仓库和普通日志。
- 所有回调需要校验签名、防重放并记录必要审计信息。
- 密钥配置通过环境变量或专用密钥管理能力注入。
- 对绑定、解绑、发布和重试等关键操作记录审计日志。
- 对外错误信息不得泄露密钥、请求签名或内部堆栈。
- 提供隐私政策、用户服务协议、使用说明和客服入口。

## 10. 最小验收标准

1. 已订购的 1688 测试账号能够从“使用服务”进入应用，无需二次登录。
2. 同一个账号能绑定至少两个微信小店，并能验证各自凭证。
3. 可粘贴 1 至 20 个真实 1688 商品链接并成功读取资料。
4. 可修改标题、类目、售价和库存，并删除主图。
5. 可一次选择多个微信小店发布。
6. 每个“商品 × 店铺”独立执行并记录结果。
7. 至少一个普通类目商品能成功提交微信审核。
8. 失败任务能显示可理解的原因并支持单独重试。
9. 用户可手动刷新微信审核/上架状态。
10. 不同 1688 账号之间的数据严格隔离。
11. 前端、接口响应和日志中不出现微信 AppSecret 或完整 Token。

## 11. 开发前仍需验证的接口事实

这些事项不改变产品范围，但必须在编码前通过官方文档和 API 测试确认：

> 审核风险：截至 2026-08-27，官方“代发解决方案（服务商版）”8.5 版方案概述包含下游商品铺货和订单自动回流。当前 V1 为了快速提审，明确暂缓订单回流；这可能成为审核补充项。先按已确认的最小铺货版本开发，如平台审核要求，再补最小订单回流闭环。

- 当前 1688 AppKey 实际获权的接口清单及字段范围；
- 货源搜索和默认推荐是否有可直接调用的接口；
- 1688 OAuth/日常授权回调的参数、签名和用户标识；
- 微信小店商品创建、图片上传、类目、属性、SKU、库存及状态查询接口；
- 微信类目资质与必填字段的动态获取方式；
- 重复铺货时微信侧的幂等和重复商品处理策略；
- 1688 与聚石塔对微信 API 出塔访问的备案或审核要求；
- 聚石塔 SAE 测试及正式环境的负载均衡、NAT 和固定出口 IP 配置。
